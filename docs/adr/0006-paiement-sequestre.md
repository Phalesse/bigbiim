# ADR 0006 — Paiement et séquestre

Statut : accepté sur le principe (document §3.10, §6.5). Grand livre en partie double immuable ; fonds détenus via un partenaire de paiement agréé (jamais par la plateforme seule) ; idempotence obligatoire ; réconciliation quotidienne. Choix de l'agrégateur : à faire (DECISIONS-A-CONFIRMER n°8).
