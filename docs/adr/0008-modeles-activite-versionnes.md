# ADR 0008 — Modèles d'activité versionnés et immuables

Statut : accepté (document §3.15). Ajouter une activité = publier un modèle, sans déploiement. Une version publiée est immuable (déclencheur SQL) ; un projet reste attaché à sa version. Extensions : niveau 1 configuration, niveau 2 événements et webhooks, niveau 3 plugin de code (rare).
